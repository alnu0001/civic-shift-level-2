# City Ranger — GitHub Pages Package

## What to upload

Upload all files in this package while keeping the folders intact.

- `index.html` is the main playable game.
- `level-1/index.html` is a direct Level 1 route.
- `.github/workflows/pages.yml` deploys the site through GitHub Actions.

## GitHub Pages setting

Repository **Settings → Pages → Source → GitHub Actions**.

After upload, wait for the **Deploy City Ranger to GitHub Pages** workflow to receive a green check.

## Controls

- Click response-plan buttons in order: signal priority, roadblock, tow unit, clear route.
- Keys 1–4 use the same commands.
